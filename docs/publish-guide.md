## Upload

1. Create a public repository named `IoT-Forensics-Testbed` under your GitHub account. Leave the repository initialization options unchecked because this package already includes a README.
2. Extract the ZIP on your computer. Upload the **contents** of the `IoT-Forensics-Testbed` folder, preserving all subfolders. Do not upload only the ZIP or an extra wrapper directory.
3. Include `.gitignore` if using a Git client; it may be hidden in your file browser.
4. Commit the files, set the About description, website, and topics, then pin the repository on your profile.
5. Verify the README images, three scenario links, article link, and repository links after upload.

No remote repository has been created or pushed as part of preparing this package.

## Main profile replacement text

After creating the repository at the suggested URL, use this in your profile README:

```markdown
### Digital Forensics and IoT Evidence Generation

Designed and implemented a two-node Raspberry Pi IoT forensics testbed used in DGFR 471. Node 1 stores DHT11 environmental readings in MySQL; Node 2 records light, motion, tamper, and USB events on external SSD storage. Includes selected source code, evidence samples, and three student investigation scenarios. Node 1 source, two Node 2 acquisition components, and a unified browser dashboard remain pending in the public release.

[GitHub case study](https://github.com/atdhebuja/IoT-Forensics-Testbed) · [Architecture and article](https://www.atdheb.com/iot-forensics-testbed-for-digital-evidence-generation/) · [Teaching demonstrations](https://www.youtube.com/@atdhebuja)
```
