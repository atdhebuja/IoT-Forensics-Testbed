# DGFR 471 student investigations

Prepared by Prof. Dr. Atdhe Buja for Fall 2026. Each activity provides a 50-minute group testbed session followed by analysis and reporting. The complete supplied Word handouts are preserved in `original-documents/`; Markdown versions provide convenient browsing.

| Scenario | Question | Needed artifacts |
| --- | --- | --- |
| [1 Physical access and tampering](scenario-1.md) | What activity is supported by the physical sensor records? | Light, motion, tamper CSVs and Node 2 event log for the assigned window |
| [2 USB activity](scenario-2.md) | What insertion/removal activity can be established? | USB CSV, kernel/journal exports, supporting physical events where available |
| [3 Distributed correlation](scenario-3.md) | Can environmental and physical observations be correlated? | Node 1 MySQL export, Node 2 records, and time-reference information |

Common deliverables: evidence worksheet, integrity notes, source-cited timeline, 3–5-page report, supporting screenshots, and explicit limitations. The handouts include a 100-point rubric. This repository's sample data is not a full scenario evidence pack; the instructor supplies complete incident-window artifacts. Original handouts retain their course submission instructions; external users should adapt those instructions to their own setting.
